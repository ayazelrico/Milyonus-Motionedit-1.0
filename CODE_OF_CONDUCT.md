# Code of Conduct

We pledge to make participation in Milyonus a harassment-free experience for everyone.

**Expected:** respectful, constructive, inclusive communication; accepting feedback gracefully.
**Unacceptable:** harassment, discrimination, personal attacks, publishing others' private information.

Maintainers may remove, edit, or reject contributions that violate this code, and may ban
contributors for behavior they deem inappropriate. Report issues to the maintainers via a
private channel listed on the repository profile. This code is adapted from the Contributor Covenant 2.1.
