# Contributing to Milyonus

Thanks for helping! 

1. Fork and clone the repo, then `npm install` and `npm run build`.
2. Create a branch: `git checkout -b feat/my-change`.
3. Keep changes focused; add or update docs and examples when behavior changes.
4. Run `npm run typecheck` and `npm test` before opening a pull request.
5. Open a PR describing *what* changed and *why*.

## Ground rules
- Do not copy code from other projects whose licenses are incompatible with MIT.
- Public APIs need TSDoc comments.
- Be kind. See the Code of Conduct.
